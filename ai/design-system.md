# Aether UI — Design principles

Clarity, restraint, hierarchy, consistency, adaptability, accessibility. Inspired by Apple platform design principles without copying proprietary assets. System font stack, semantic tokens, subtle elevation, intentional motion. Support light and dark modes. Default comfortable density; compact density is optional and must retain accessible targets.

Source of truth: `tokens/core`, `tokens/semantic`, `tokens/components`, then `specifications`. When instructions conflict, accessibility requirements take precedence and the conflict must be reported.
