# Create or extend an Aether UI component

```text
Design the framework-neutral contract for [COMPONENT OR EXTENSION].

Before proposing it:
- read AGENTS.md and ai/design-system.md;
- compare the need with every existing component contract;
- explain why composition or an existing variant is insufficient.

Define purpose, non-goals, API, sizes, variants, every state, keyboard behavior,
focus management, accessible naming, responsive behavior, motion, and required tokens.
Update the visual documentation and tests. Do not implement a framework adapter until
the contract is complete and internally consistent.
```
