# Generation rules

1. Read the relevant tokens and component specifications.
2. Use semantic tokens, not arbitrary hex values.
3. Prefer an existing component; do not silently invent variants.
4. Include keyboard navigation, visible focus, labels, disabled/loading states, and responsive behavior.
5. Respect reduced-motion preferences and theme switching.
6. Keep business logic separate from visual components.
7. Document any missing token, component or interaction.
8. Verify the generated UI against `ai/review-checklist.md`.
