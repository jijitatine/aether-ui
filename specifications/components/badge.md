# Badge

Display a short status or count beside the content it describes.

| Variant | Options |
| --- | --- |
| `status` | Visible label and a tone of neutral, info, success, warning, or danger. |
| `count` | Non-negative count, optional display cap, and accessible context that identifies what is counted. |

Use semantic colors in both themes. A status always has a text label. Treat the
status dot as decorative. Badges have no independent tab stop. Keep counts
readable as their width grows. When a cap is shown, expose the exact count or
the capped meaning to assistive technology. In interactive contexts, include the
count in the accessible name or description of its associated control.
