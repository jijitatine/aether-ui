# Radio

Use radio buttons when exactly one option can be selected in a group. Give each group a visible name and each option a clickable label. On web, use native radio inputs with a shared name, distinct values, and a fieldset with a legend.

Support unselected, selected, focus-visible, and disabled states. Native keyboard navigation uses Tab to enter or leave the group and arrow keys to move the selection. Use the semantic accent and text tokens, and give labels a touch target of at least 48px in height. Use required when the form needs a selection.
