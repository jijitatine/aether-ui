# Bulk actions

Show a selection count and contextual actions when one or more rows are selected. Use native checkboxes for individual rows and a tri-state checkbox for all eligible visible rows. Filtering removes hidden rows from the selection; sorting preserves the selection. Disabled rows are excluded.

Provide a clear-selection action and announce changes politely. Confirm archiving in a Dialog and announce success with a Toast. Cancellation preserves the selection. When an action hides the bar, move focus to the select-all checkbox or an available control nearby. Use semantic surface, border and accent tokens. A mobile table can pin the bar above the bottom safe area and reserve scroll space for it.
