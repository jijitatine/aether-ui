# Stepper

Use an ordered list to show the current, completed and upcoming stages of a linear form. Completed stages can be revisited on wide screens. On narrow screens, show the current stage and total, with Previous and Next controls.

Validate the active stage before moving forward. Keep entered values when navigating back. Mark the current stage with aria-current=step, and move focus to the newly visible panel when navigating. A review stage can summarize values before submission. Use the existing Button and field styles with semantic surface, text, accent and border tokens.
