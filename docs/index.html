Commencer

Utilisez les tokens aujourd’hui. Les adaptateurs framework arriveront sans modifier les contrats.

1

Cloner

Récupérez la source et les spécifications.

git clone https://github.com/jijitatine/aether-ui.git
2

Charger les tokens

Importez les propriétés CSS générées.

<link rel="stylesheet" href="packages/tokens-css/tokens.css">
3

Construire

Appliquez les tokens sémantiques et les contrats.

npm run build:tokens
npm test

02

Principes

Une profondeur inspirée d’iOS qui clarifie les niveaux sans prendre le dessus sur le contenu.

Clarté

Une hiérarchie lisible, un vocabulaire direct, une action principale évidente.

Verre utile

La transparence signale une couche, une navigation ou un contexte temporaire — jamais un simple décor.

Adaptabilité

Chaque composition reste robuste du mobile au grand écran, en clair comme en sombre.

✓

Accessibilité

Contraste, réduction de transparence, clavier, toucher et lecteurs d’écran sont des exigences.

      Après

      Tester thèmes, clavier, responsive, erreurs et mouvement réduit.

      07

      Faire évoluer Aether UI

      Chaque ajout commence par un besoin reproductible et se termine par un contrat vérifiable.

      1. 1

        Décrire le besoin

        Usage, utilisateurs, contraintes et alternatives existantes.

      2. 2

        Étendre les tokens

        Uniquement lorsqu’aucun rôle sémantique actuel ne convient.

      3. 3

        Écrire le contrat

        API, états, interactions, responsive et accessibilité.

      4. 4

        Démontrer et tester

        Documentation visuelle, thèmes et tests automatisés.
